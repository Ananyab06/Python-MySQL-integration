# Python-MySQL integration module

This repository demonstrates how a Python application connects to a MySQL database to query 
and filter information.

## Tech Stack
- Python (mysql.connector)
- MySQL

## Features
- Establishes secure database connection from Python
- Runs SQL queries to fetch and filter hotels based on user input
- Demonstrates structured database schema for city data

## How to Run
1. Install mysql-connector-python
2. Import the database using schema.sql
3. Run db_connection.py
